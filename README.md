# 🏠 Nest — Home Digital Twin

> 运行在口袋里的家庭数字孪生体。离线优先，确定性算法，无感感知家的状态。


---

## 产品愿景

Nest 不是一个传统的智能家居控制平台，它不依赖任何繁重的云端 AI，也不需要购买昂贵的传感器套件。

作为一款运行在 iPhone/iPad 原生环境中的应用，它的核心目标只有一个：**用严谨的脱机推演算法，帮你看清家里正在悄悄发生的事**。

- 饮用水还剩几天？
- 抽纸和猫粮快见底了吗？
- 猫厕所有多久没铲了？
- 浴室的淋浴间有多久没有彻底打扫？

这些问题的答案不再需要主观猜测。只需要你在日常的"关键节点"（如拆除了包装封条、换上了新的水桶）随手记录一下——剩下的推演工作，全部交给本地算法引擎。

---

## 核心设计原则

| 原则 | 含义 |
|---|---|
| **离线优先 (Local-First)** | 所有计算在 iOS 本地沙盒内跑通，极度保护隐私。即便没有网络，算法推演也照常运行。 |
| **严谨的确定性算法** | 严禁生成式大模型 (LLM) 介入业务数据的计算。所有库存水位和清洁度的推演全部基于严谨的数学规律。 |
| **零阻力录入** | 以"换水"、"开封"、"铲屎"等低频动作为核心特征提取点，彻底消灭频繁记录带来的疲惫感。 |

## 核心功能模块

### 🏠 主控仪表盘 (Dashboard)
全局信息驾驶舱，摒弃无效图表，只展示明确的结果和你的"行动点"。
- **核心指标卡片**：各业务模块的实时状态快照（水资源水位、物资库存健康度、区域清洁度）。
- **智能管家晨报**：当你在清晨首次唤醒应用时，由拟人化管家播报昨日的数据摘要与今日预警。
- **动态预警**：当核心算法检测到某种物资消耗速率超出阈值时，触发系统级本地推送提示。

---

### 💧 饮用水管理 (Water Steward)
基于时间衰减动态算法的水位推演引擎。
- 以"换水"这单次动作为核心锚点，自动且平滑地推演剩余水量。
- 结合家庭成员基数（`family_member_count`）与作息时间，动态校准日消耗基准线（如睡眠时段暂停水位计算）。
- 优雅地提供实时剩余百分比进度及"预计剩余可用天数"。

---

### 📦 消耗品库存 (Inventory)
根治家庭物资的"断供焦虑"，同时抑制盲目的"过度囤积"。
- 捕捉"开封"动作作为唯一核心系统入口，精确记录每次从储备区取用物品的时间戳。
- 引入 **60天滑动窗口 (Sliding Window)** 算法，精准运算不同商品的真实消耗速率。
- 智能预测囤货可支撑的绝对天数，进入"3天枯竭期"或触及安全阈值时拉响视觉预警。
- UI 层的视觉堆叠：使用生动的拟物/Emoji 矩阵直观呈现库存的厚度。

---

### 🧹 清洁管理 (Hygiene)
基于正向计时逻辑，冷酷地量化"到底有多久没打扫了"。
- 以点击"完成打扫"为时钟原点，实时为每一个卫生区块计算清洁紧迫度。
- 卫生区域的视觉整洁度评分随时间推移进行非线性衰减，一旦超期便触发应用内视觉界面的老化或污浊蒙版提醒。

---

### 🐱 宠物护理 (Pet Care)
复用且重载了清洁模块的衰减与紧迫度算法，专为多宠家庭场景深度定制。
- 追踪投喂、铲屎、换水、洗澡、内外驱虫等低频但强周期的护理事项。
- 针对多只宠物的环境，算法自动激活资源加速乘子（如设定 `LoadFactor = 1.x`，使共享饮用水/猫砂盆的衰减速度成比例增加）。
- 搭载第一人称视角傲娇文案，增强铲屎官的情感羁绊与执行驱动力。

## 技术架构演进

Nest 项目经历了一次重大的生态跨越。它始于 Web 技术栈的快速原型验证，现已全面拥抱 Apple 生态，转向纯原生应用开发。

### 阶段一：Web 原型验证 (已归档)
- **前端**：React, TypeScript, Vite
- **后端**：Express.js 服务, `better-sqlite3` 管理 SQLite 本地数据库
- **状态**：成功跑通水管家、库存、宠物及清洁模块的核心数学推演逻辑与算法实验。

### 阶段二：iOS 原生架构 (当前主线)
- **客户端呈现**：纯原生 **Swift / SwiftUI** 开发，提供极致流畅的沉浸式交互及平滑的微手势动效。
- **本地算法引擎**：基于 Swift 重新构建了底层的脱机时间推演沙盒，确保与 iOS 的应用生命周期、后台刷新及能耗管理机制完美契合。
- **数据本地化持久**：重构存储层以深度适配 iOS 本地存储环境 (涵盖本地关联关系及无缝的异步存取)，进一步贯彻 Local-First 设计原则。

## 本地编译与运行 (iOS 主线)

**前置要求：** macOS 环境，安装 Xcode 15 或更高版本。

1. 克隆代码仓库并在 Xcode 中打开项目文件。
2. 配置好您的 iOS 模拟器（推荐 iPhone 15 或更高分辨率机型）或直接连接实体 iPhone 授权编译。
3. 点击 **Run (⌘ + R)** ，即刻在本地体验丝滑的家庭数字孪生。

> *注：如果您因研究需要运行早期的 Web 验证版，请切换至对应的历史分支目录，执行 `npm install` 与 `npm run dev` 即可唤起 Web 仪表盘。*
